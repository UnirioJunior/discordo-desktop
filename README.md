<h1 align="center">Discordo para Windows</h1>

<p align="center">Seu grupo, sua tela, todo mundo junto.</p>

## Baixar

1. Abra a [última versão](https://github.com/UnirioJunior/discordo-desktop/releases/latest).
2. Baixe o arquivo **`Discordo-Setup-….exe`** e abra.
3. Pronto. O Discordo se atualiza sozinho sempre que sair uma versão nova.

> Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois
> em **Executar assim mesmo**. Isso aparece porque o instalador ainda não tem certificado de
> assinatura de código; cada atualização é conferida pelo próprio app com uma assinatura digital.

Este repositório guarda só os instaladores. O código do Discordo é privado.
